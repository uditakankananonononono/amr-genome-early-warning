# G5 tool - PASS (tool runs on held-out date-split isolates)
tool/amr_ew.py: input = species + AMRFinderPlus genotype list + year. Output per drug: R/S call, probability, the model's honest date-split balanced accuracy (not the random-split number), per-determinant early-warning flags (from G2), unseen determinants (information only; G3 showed novelty does not predict misses), and bla structural proximity (G4).
Validation (tool/validate_tool.py): 30 random 2020+ isolates (seed 42), 77 drug calls, accuracy 0.870. All 7 missed resistant calls carried an early-warning flag, but so did 6 of 9 correctly called resistant ones (67%). Flags were derived on the same date-test set, so this is in-sample and optimistic. It shows the flags are sensitive but not specific; this is a limitation, not a validated early-warning claim.
